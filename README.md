# Häkchen-Testseiten (gc-haekchen-v1)

Testfassungen aller Bewerberseiten mit den zwei getrennten Häkchen (Pool / Stellenangebote per E-Mail).
Gebaut aus den Live-Seiten mit `Coding/claude-tools/funnel_haekchen/build_testseiten.py` – nicht von Hand ändern.
Absendungen werden als TEST markiert, Kunden-Funnels schreiben in den Tab „00 Testfirma GmbH“, Meta-Pixel ist aus.
